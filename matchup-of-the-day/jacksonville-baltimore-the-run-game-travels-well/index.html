The Part of Baltimore That Travels

The Ravens' best trait is one that shouldn't depend on the building.

The Ravens run for 133.5 yards a game at 4.6 a carry, and that's the best thing about a 4-4 team. Those marks rank 6th and 7th in the league, so this is upper tier work rather than the very top of the board. The per carry number matters more than the total, because volume alone can be a byproduct of protecting leads. A team with a -24 point differential hasn't been salting away many games, which suggests Baltimore is earning those yards in competitive football.

The travel case starts with the record: Baltimore is 3-2 on the road and 1-2 at home. We don't have the rushing numbers split by venue, so nobody should claim the ground game alone won those road games. What we can say is that a rushing attack this efficient doesn't need a friendly building, and Baltimore's results away from home have been better than its results in its own. The job now is to bring that form back to M&T Bank Stadium, against a team that arrives 5-2.

The edge

At 4.6 a carry, Baltimore's run game is the one part of this team that has earned its reputation.

Jacksonville Keeps It Closer Than You'd Think

The Ravens lead on the ground, but the Jaguars aren't far behind.

Baltimore does hold the edge on the ground, but it's narrower than the headline stat suggests. Jacksonville runs for 122.9 a game at 4.3 a carry, ranked 13th and 12th, against Baltimore's 133.5 and 4.6. That's a real gap, and it favors the Ravens in both volume and efficiency. It just isn't the kind of gap that decides a game by itself.

The Jaguars' numbers also come from only 7 games, so these rates are still early and one big afternoon can move them. The more important point is what the run does for each offense. Jacksonville pairs a middle of the pack ground game with 7.44 yards per pass attempt, 3rd in the league, so its run game is a complement. It doesn't have to be the whole plan.

The catch

Baltimore needs the run to work. Jacksonville would simply like it to.

Why Baltimore Needs the Run So Badly

The passing numbers explain how much weight the ground game carries.

Baltimore's passing game explains why the run carries so much weight. The Ravens throw for 205.1 yards a game, 21st in the league, at 6.56 yards per pass attempt. Their 67.5 completion percentage ranks 6th, which makes that yardage more telling: they're completing throws without getting much from them. Jacksonville completes fewer at 65.2 percent, ranked 13th, and still gets 7.44 yards per attempt and 227.4 passing yards a game, 16th.

That shape makes the run the engine of this offense. Total yardage barely separates the two teams, 365.4 a game for Jacksonville at 10th and 356.6 for Baltimore at 12th, and more of Baltimore's comes on the ground. If the Ravens stay ahead of the chains by running, a modest passing game can fit neatly around it. If they're stuck throwing on long yardage, they're asking the weaker half of the offense to do the heavy lifting.

The tell

A 67.5 completion percentage at 6.56 yards per attempt is an offense that needs the run to set the terms.

Where the Ground Edge Leaks Away

A good run game should pay off on third down and near the goal line.

Running well should make third downs shorter, and this is where Baltimore's ground edge hasn't fully converted. The Ravens convert 39.2 percent of third downs, 14th in the league, while the Jaguars are at 48.2 percent, 3rd. Baltimore picks up 18.5 first downs a game to Jacksonville's 20.9. So the team with the better run game is the one that's worse at staying on the field, and that's the uncomfortable fact in this matchup.

The red zone tells the same story. Jacksonville scores touchdowns on 68.4 percent of its trips, 7th in the league, and Baltimore sits at 59.3 percent, 15th. A run game is supposed to pay its biggest dividend in tight space, so a rate that ordinary is a warning. Baltimore needs its 4.6 yards a carry to end in touchdowns, because this opponent's offense finishes drives.

The problem

The better rushing team is the worse third down team, by 39.2 percent to 48.2 percent.

The Scoreboard Decides How Long Baltimore Can Run

Jacksonville's best answer to a ground game may be an early lead.

A ground game needs a scoreboard that lets it keep running, and that's Jacksonville's best counter. The Jaguars score 28 a game and allow 15.9, good for a +85 point differential in 7 games. The Ravens score 22.4 and allow 25.4, which is how you get to -24 over 8 games. Baltimore can't run its way through this if it falls behind early and has to throw.

Turnovers push the same way. Jacksonville's +7 turnover differential is 1st in the league, built on 12 takeaways against 5 giveaways, while Baltimore is at 0 with 8 of each. We don't have what the Jaguars allow on the ground, so the run matchup itself stays an open question, and their road record is just 1-1. That's the case for Baltimore: if the run holds up and the ball stays secure, the Ravens can shorten this game and keep it close. The Jaguars still have more ways to win it.

The counter

Jacksonville doesn't have to stop the run outright. A lead and a +7 turnover differential can take it off the table.
