Baltimore Wins With the Run

The Ravens' offense starts and ends on the ground.

Baltimore runs for 137.8 yards a game, 5th in the league, and it does it at 4.7 yards a carry, which ranks 6th. Those two numbers together matter more than either alone. Plenty of teams pile up rushing yards by running a lot; the Ravens are piling them up while staying efficient on every attempt. That's the profile of a run game that dictates terms rather than one that just eats clock.

Put it next to the total and the picture sharpens. The Ravens average 342.4 total yards a game, ranked 16th, so the offense as a whole is middle of the pack. Strip away the ground game and there isn't much left that scares anyone. This is a team whose ceiling on any given Sunday is set by how well it runs the ball.

The edge

Baltimore isn't just running often. It's running well, 4.7 a carry, and that's the whole offense.

The Run Keeps the Passing Game Honest

A modest air attack that stays on schedule.

The passing numbers tell you what kind of quarterbacking this run game buys. Baltimore throws for just 188.4 yards a game, 24th in the league, yet completes 66.8 percent of its passes, which ranks 5th. Low volume, high accuracy: that's what it looks like when defenses are cheating toward the run and the throws come in favorable spots.

The Ravens move the chains for 17.6 first downs a game, and you can see how the run feeds that. Second and short is a different down than second and long, and a team running at this level lives in the first kind. It doesn't need a vertical passing game to sustain drives. It needs the run to keep working, and against this opponent there's little reason to think it won't.

The edge

A 66.8 completion rate on limited volume is a passing game living off what the run creates.

What the Chargers Bring to Stop It

No pressure, and a scoreboard that keeps leaking.

To be honest about the limits of the data, there's no direct rushing defense figure in this set for Los Angeles. What there is doesn't flatter them. The Chargers allow 27.4 points a game and carry a -98 point differential through an 0-8 start. Teams that give up that much generally aren't winning the line of scrimmage.

The pass rush is the clearest tell. Los Angeles has 13 sacks, 31st in the league, so this front isn't creating negative plays that knock an offense off schedule. It has 12 takeaways, ranked 15th, which is ordinary rather than disruptive. A defense that neither gets into the backfield nor forces mistakes at an unusual rate is exactly the kind a steady run game grinds down.

The edge

Thirteen sacks, 31st in the league. A front that can't get into the backfield won't blow up Baltimore's runs either.

The Chargers Can't Force a Shootout

Why Baltimore never has to abandon the plan.

The best thing that can happen to a run first team is an opponent that can't score, and Los Angeles scores 15.1 points a game. The Chargers total 316.4 yards a game, 25th, and throw for 177.1, ranked 27th, at 5.17 yards an attempt with a 60.1 completion percentage that sits 26th. Their own ground game is perfectly average at 114.5 yards a game, 15th, and 4.1 a carry, 16th. Nothing here threatens to turn this into a track meet.

The situational numbers are worse. Los Angeles converts 34.2 percent on third down, 29th, and scores touchdowns on 47.4 percent of red zone trips, 28th. Drives stall, and the ones that don't often end in field goals. That's the game script Baltimore wants: it never falls far enough behind to stop handing the ball off.

The edge

An offense scoring 15.1 a game never forces Baltimore to put the run game away.

Turnovers Shape the Script

Los Angeles gives the ball away at an alarming rate.

The Chargers have 19 giveaways, 2nd most in the league, and a -7 turnover differential that ranks 28th. Baltimore isn't a ballhawking team, with 9 takeaways ranked 23rd and a -2 differential that sits 20th, but it doesn't need to be special here. It just needs Los Angeles to keep being itself. Short fields turn a good run game into a great one.

The Ravens' own 11 giveaways rank 17th, so this isn't a spotless offense either. Discipline is a wash: Los Angeles has 540 penalty yards, Baltimore 539. That puts the margin back where the article started. If neither team is gifting yards through flags, the team that can manufacture them on the ground holds the advantage.

The edge

Nineteen giveaways means short fields, and short fields are where a run game finishes drives.

Where the Ravens Case Gets Thinner

A losing record and a strange home split.

Baltimore is 4-5 with a -47 point differential, scoring 21 a game and allowing 26.2. That's not a team that should be laying the wood on anybody without a reason. The run game really has traveled: the Ravens are 3-2 on the road but just 1-3 at home, which is the oddest note in this matchup. Whatever has gone wrong in Baltimore hasn't been the ground attack, but the split is real.

The finishing numbers are merely average too, 37.8 percent on third down, 18th, and 59.3 percent red zone touchdowns, 16th. So the run gets them into scoring position more reliably than it gets them into the end zone. Against a Chargers team that is 0-4 on the road, though, Baltimore doesn't need to be sharp. It needs to do the one thing it does at a top of the league level, and keep doing it.

The edge

The Ravens' flaws are real, but none of them involve running the football.
