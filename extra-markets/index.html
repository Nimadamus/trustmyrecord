What Extra Markets shows

This page lists alternate lines: the same game offered at different numbers than the main board, each with its own price. Two kinds of full game market appear here when the feed has them. Alternate spreads are the run line in baseball, the puck line in hockey and the point spread in football and basketball, moved up or down. Alternate totals are the game total set higher or lower than the main number.

The trade off is always the same. Moving a line in your favor costs you price, and taking a harder number pays more. For example, if a team is favored by 3.5 on the main board, an alternate list might offer that team at 1.5 for a shorter price or at 6.5 for a longer one. Nothing here is a better bet by default; it is a different bet on the same game.

Where the numbers come from

Alternate lines are read from Bovada's public feed, separately from the feed behind the main sportsbook board, so nothing on this page changes the prices you see there. Only full game markets are shown. To lock a pick on an alternate line, use the Alt Lines tab on the Sportsbook; this page is a read only view.

Why a sport can be empty

A sport only shows games when the book has alternate lines posted for them. Between seasons, on days with no games, early before lines go up, and once a game has started and its markets come down, the list for that sport will be empty, and the page says so instead of showing old numbers. If the feed itself cannot be reached, the page tells you that too.

How it updates

The page asks the feed for the current list every time you open it or switch sports, so reloading always shows the latest numbers the feed has. Lines move often, so the price when you lock a pick is the one that counts.
